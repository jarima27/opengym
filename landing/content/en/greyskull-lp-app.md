# Greyskull LP, *no calculator needed*

Greyskull LP is linear progression with a final set taken to failure. Tiza runs it for you: it reads that set, sets next session's weight and tells you why.

[Start free](app)
:::

## How Greyskull LP works in Tiza

- **Two straight sets and a final set to failure**: that last set is the one that counts.
- **Beat the target and the weight goes up** next session.
- **Double the target reps** on that set and it goes up twice as much.
- **Miss, and it resets 10 %** so you build back from there.

The increment is 2.5 kg (5 kg for legs, hips and back), and you can change it per exercise.

::: steps
## Set it up in two minutes

### Create your routines
For example two workouts, A and B, with your main lifts. You can start from an included plan and swap exercises.

### Pick "Greyskull LP" as the progression
In the progression settings of the routine or of each exercise.

### Train
Tick your sets. When you finish, the next load is already worked out, with the reason in view.

## Greyskull LP questions

### Can I mix Greyskull LP with other progressions?
Yes. Progression is chosen per routine or per exercise: Greyskull LP on the main lifts and double progression on accessories, for example.

### What if I skip the set to failure one day?
Tiza reads what you log: if that set wasn't done, it counts as a miss and the reset applies. You always see which rule it applied and why.
